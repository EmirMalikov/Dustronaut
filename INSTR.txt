DUSTRONAUT: 7 АРХИВОВ ДЛЯ ПЛОЩАДОК
==================================
В каждом архиве в корне лежат index.html, game.js, three.min.js (у GameDistribution ещё config.js).
Внешних шрифтов и CDN нет, весь код сжат (минифицирован), отладочный режим убран.
Админ-команды в консоли (S.coins, travel и т.д.) по-прежнему работают.

ЗАЩИТА (sitelock): архив для площадки запускается только на её доменах и на localhost.
Если кто-то украдёт файлы и выложит на свой сайт, вместо игры покажется надпись
"Эта копия запущена на чужом сайте" и ссылка на itch.io.
ПОЭТОМУ: каждый архив загружай ТОЛЬКО на свою площадку. Архив Яндекса на CrazyGames не заработает.
Без замка: itch.io (у itch есть свой автоматический замок) и Poki (у Poki свои правила и свои сервера).

ВАЖНО ПРО POKI: Poki берёт игры эксклюзивно для веба. Если Poki примет игру, её нельзя держать
на других веб-сайтах с играми (Steam и мобильные магазины можно). Реши заранее: Poki или все остальные.

----------------------------------------------------------------
1. dustronaut_yandex.zip -> Яндекс Игры
   1) games.yandex.ru/console -> войти -> "Добавить приложение".
   2) Вкладка "Черновик": загрузи архив, заполни название, описание (RU и EN), иконку, обложку,
      скриншоты (размеры написаны прямо в форме), категорию, языки RU и EN.
   3) Открой игру из черновика и проверь: старт, сохранения, реклама за турбо.
   4) "Отправить на модерацию". Если вернут с замечаниями - пришли текст.
   Замок пускает: *.yandex.*, playhop.com, localhost.

2. dustronaut_crazygames.zip -> CrazyGames
   1) developer.crazygames.com -> "Submit game" / "Add game" -> HTML5.
   2) Если форма не принимает ZIP - распакуй и загрузи 3 файла по отдельности.
   3) Проверь игру в их QA-инструменте (Preview) и отправь на Basic Launch.
      SDK уже встроен, поэтому после Basic Launch сразу подходит и для Full Launch (реклама).
   Замок пускает: все домены crazygames.*, localhost.

3. dustronaut_poki.zip -> Poki (только если выбираешь Poki, см. выше)
   1) developers.poki.com -> создай аккаунт и игру -> "Upload new version" -> архив.
   2) Прогони игру через Poki Inspector, он покажет, что исправить.
   3) Дальше Poki сам проводит тесты (Player Fit Test, Web Fit Test). Игры отбираются вручную.

4. dustronaut_gamedistribution.zip -> GameDistribution
   1) developer.gamedistribution.com -> "Add game" -> создай игру, скопируй Game ID.
   2) Распакуй архив, открой config.js блокнотом, вставь Game ID между кавычек, сохрани.
   3) Снова запакуй 4 файла в ZIP (файлы в корне, без папки) и загрузи в кабинет.
   Замок пускает: html5.gamedistribution.com (игру можно встраивать на сайты-партнёры GD, это нормально).

5. dustronaut_itchio.zip -> itch.io
   Edit game -> Uploads -> удали старый файл -> загрузи этот ->
   галочка "This file will be played in the browser", остальные платформы не отмечай -> Save.

6. dustronaut_newgrounds.zip -> Newgrounds
   1) newgrounds.com -> вверху "Upload" (или newgrounds.com/projects/games) -> новый проект.
   2) Тип: HTML5, загрузи ZIP. Размер окна поставь 960 x 540, включи полноэкранный режим, если есть галочка.
   3) Заполни описание, иконку, теги -> Publish.
   Замок пускает: newgrounds.com, ungrounded.net (сервер файлов Newgrounds).

7. dustronaut_gamejolt.zip -> Game Jolt
   1) gamejolt.com -> Dashboard -> "Add game".
   2) В игре: Packages -> добавь пакет -> New release -> "Upload browser build" -> ZIP, тип HTML.
   3) Размер 960 x 540 (или "fit to screen"), сохрани и опубликуй релиз, потом саму игру.
   Замок пускает: gamejolt.com и gamejolt.net.

----------------------------------------------------------------
ЕСЛИ ИГРА НА ПЛОЩАДКЕ ПОКАЗЫВАЕТ "запущена на чужом сайте":
значит площадка грузит файлы с домена, которого нет в списке. Пришли адрес из консоли
(F12 -> Console -> location.href в окне игры), добавлю домен и пересоберу.
Что я не мог проверить: настоящие SDK площадок и их реальные сервера (проверял на имитации доменов).
